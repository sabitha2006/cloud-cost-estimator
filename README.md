# Cloud Cost Estimator

## Project Overview

Cloud Cost Estimator is a web-based application that helps users estimate AWS cloud service costs based on service selection and monthly usage.

## Features

* Multiple AWS services

* Monthly cost calculation
* Yearly cost calculation
* User-friendly interface
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## AWS Services Included

* Amazon EC2
* Amazon S3
* Amazon RDS
* AWS Lambda
* Amazon CloudFront

## Project Workflow

1. Select AWS Service
2. Enter Monthly Usage Hours
3. Calculate Cost
4. View Monthly and Yearly Estimates

## Future Enhancements

* Real-time AWS pricing API
* Cost comparison charts
* Multi-service cost estimation
* Export report as PDF
